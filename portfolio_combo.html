Project 01 | Indoor Telemetry Dashboard

A real-time indoor positioning system built during a hackathon. An Android app (Kotlin) scans three fixed BLE anchor beacons, filters noisy RSSI readings using variance thresholding, and computes position via weighted trilateration. It fuses BLE data (70%) with IMU-based dead reckoning from the accelerometer and gyroscope (30%) to keep tracking stable even when signals drop. Coordinates are pushed to Supabase every 300ms and visualized live on a React web dashboard — showing the device as a moving dot on a 2D grid with real-time distance and signal strength for each anchor. Tech: Kotlin · Android BLE API · OkHttp · React (Vite) · Supabase Realtime

Project 02 | Touchless Cyber Canvas

Air Draw AI is a touchless, high-performance air-drawing application built on a decoupled client-server architecture. By shifting computer vision processing from the server to client-side GPU execution via the MediaPipe Hands JS SDK, the application delivers a zero-latency, 60 FPS vector drawing experience. The frontend synchronizes stroke coordinates and undo/redo history using a low-overhead FastAPI WebSocket server, backed by a secure SQLite authentication database.

Project 03 | ChromaGit

gitAnalyser is a responsive, dark-mode GitHub profile exploration web application built on React 19, Vite, Tailwind CSS, Recharts, and Axios that transforms raw developer profile data into clean visual dashboards. Designed with modularity and resilience, it leverages a custom state orchestration hook, useGithub , to concurrently retrieve user profile details, top repositories, and individual repository language metrics using Promise.all while preventing single-repository failures from disrupting page loads. Through these aggregated metrics, the application renders dynamic LanguageCharts and interactive RepoLists , providing an optimized, end-to-end interface for evaluating developer footprints.
